# Éamonn Needham

Academic website at https://eamonnneedham.com, served by GitHub Pages from `main` and the repository root.

The approved October 2026 site contains Home, About, Research, Publications & CV, Teaching and Outreach, and Gallery. Edit `content.js`, `site.js`, and `styles.css`; regenerate the initial page HTML when editing content. Photos and the current CV are in `assets/`. The `/preview/` pages redirect to the live pages.
